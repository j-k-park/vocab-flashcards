## 2단계 · 단어 관리와 학습 편의

1단계 코드가 있는 같은 폴더에서 실행한다. 끝나면 학생이 자기 단어장을 옮겨 와서 필터·단축키로 학습할 수 있다.

```text
1단계에서 만든 영단어 플래시카드 웹앱(index.html, style.css, app.js, words.js)에 2단계 기능을 추가해줘.
먼저 기존 코드를 읽고 구조를 파악한 뒤, 저장 데이터(localStorage "vocab-flashcards:v1", version 1)와 1단계 동작을 깨뜨리지 않게 작업해.
파일이 커지면 역할별로 나눠도 좋지만(예: storage.js, manage.js), 빌드 도구와 외부 라이브러리는 쓰지 마.

## 추가할 기능
1. 단어 관리 화면 (F-06)
   - 상단 바에 메뉴 버튼을 두고, 메뉴에서 "단어 관리"로 진입. 뒤로 가기로 학습 화면 복귀 (브라우저 뒤로 가기도 동작하도록 해시 라우팅 #/manage)
   - 입력 폼: 영단어·뜻(필수), 품사·예문(선택). 영단어나 뜻이 비면 추가 버튼 비활성
   - 같은 영단어(대소문자·앞뒤 공백 무시)가 있으면 "이미 있는 단어예요" 경고
   - 글자 수 제한: 영단어 50, 뜻 100, 예문 200
   - 단어 목록: 영단어·뜻·암기 상태 표시, 검색창(영단어·뜻 부분 일치), 각 행에 수정·삭제
   - 삭제는 확인 창을 거친다. 현재 보던 카드를 삭제하면 다음 카드로 이동
   - 단어가 0개면 학습 화면에 "단어를 추가해 보세요"와 단어 관리 바로가기 버튼
2. 일괄 추가 (F-10)
   - 텍스트 영역에 한 줄에 "단어, 뜻" 또는 "단어[탭]뜻" 형식으로 최대 200줄 붙여넣기 (엑셀·구글 시트에서 복사한 내용도 되도록)
   - 추가 전 미리보기에서 형식 오류·중복 줄을 표시하고, 정상 줄만 추가. 추가 후 "n개 추가, m개 건너뜀" 안내
3. 진도 표시 (F-08)
   - 상단 바에 "암기 n / 전체 m", 그 아래 높이 6px 진도 막대(암기 완료 비율)
4. 필터 · 섞기 (F-09)
   - 카드 위에 "미암기 / 전체 / 암기 완료" 탭(기본 미암기)과 섞기 토글
   - filter·shuffle 상태도 AppState에 저장
   - "미암기" 모드에서 완료한 단어는 즉시 목록에서 빠진다
5. 이전 · 단축키 · 스와이프 (F-11)
   - 하단 버튼을 "이전 · 암기 완료 · 다음" 3개로
   - 키보드: ← 이전, → 다음, Space 뒤집기, Enter 암기 완료 (입력창에 포커스가 있을 때는 동작하지 않게)
   - 모바일: 카드 좌우 스와이프로 이전/다음 (탭과 구분)
   - 폭 768px 이상에서는 하단에 단축키 안내 표시
6. 완료 화면 (F-12)
   - 현재 필터에서 남은 카드가 0개가 되면: 축하 문구, 암기한 단어 수, "처음부터 다시"(모든 암기 상태 초기화, 확인 창), "단어 추가하기" 버튼
7. 카드 전환 효과
   - 다음 카드는 왼쪽으로 밀려 나가는 슬라이드 0.25초 (reduced-motion이면 생략)
   - 암기 완료 시 버튼이 잠깐 초록으로 바뀌는 피드백
8. 학습 통계 갱신
   - 카드를 뒤집을 때마다 stats.daily의 오늘 날짜(로컬 시간 기준) +1, 연속 학습일(streak) 계산

## 지켜야 할 것
- 사용자 입력은 textContent로만 출력
- 모든 버튼 48×48px 이상, Tab 이동 순서가 자연스럽고 포커스가 보일 것
- 저장 규칙은 1단계와 동일 (변경 즉시 저장, 오류 시 백업 후 복구)
- 1단계 완료 기준이 계속 통과하는지 다시 확인

## 완료 기준 (직접 확인하고 결과를 알려줘)
- [ ] 단어 20줄을 붙여넣어 한 번에 추가되고, 오류 줄은 미리보기에서 표시된다
- [ ] 단어 수정·삭제 후 새로고침해도 반영돼 있다
- [ ] 중복 단어를 추가하면 경고가 뜬다
- [ ] "미암기" 필터에서 암기 완료하면 카드가 빠지고 진도 숫자가 바로 바뀐다
- [ ] 섞기를 켜고 새로고침해도 섞기 상태가 유지된다
- [ ] 키보드만으로 뒤집기·이전·다음·암기 완료가 모두 된다
- [ ] 마지막 미암기 단어를 완료하면 완료 화면이 나오고, "처음부터 다시"로 초기화된다

끝나면 바뀜 파일과 주요 변경점, 완료 기준별 확인 결과를 정리해줘.
```

### 구현 결과 (완료)

- 새 파일: `storage.js`(상태·저장 담당), `manage.js`(단어 관리 화면), `toast.js`(공용 토스트)
- 변경 파일: `index.html`(관리 화면·필터탭·진도바 등 마크업 추가), `style.css`(관리 화면·애니메이션 스타일 추가), `app.js`(학습 화면 로직 재구성 + 라우팅)
- 완료 기준 7개 + 1단계 회귀 기준 7개, 총 14개 항목 모두 Playwright로 자동 조작 + 스크린샷 확인 완료 (콘솔 에러 0건)
- 비고: 필터/섞기 상태는 새로고침 후에도 유지되도록 AppState에 저장. 섞기 순서 자체는 세션 동안만 유지(저장 안 함)
