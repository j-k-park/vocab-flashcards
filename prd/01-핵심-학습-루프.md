## 1단계 · 핵심 학습 루프

빈 폴더에서 시작한다. 끝나면 기본 단어 50개로 뒤집기 · 다음 · 암기 완료가 동작하고, 새로고침해도 상태가 남는다.

```text
너는 고등학생용 영단어 플래시카드 웹앱을 만드는 프론트엔드 개발자야.
아래 PRD 요약을 바탕으로 1단계(핵심 학습 루프)만 구현해줘. 2·3단계 기능(단어 관리, 필터, 발음 등)은 아직 만들지 마.

## 제품 요약
- 대상: 자투리 시간에 혼자 영단어를 외우는 고등학생 1인 (모바일 세로 화면이 주력, 크롬북·PC 보조)
- 형태: 설치·로그인 없이 브라우저에서 바로 여는 정적 웹앱 (서버 없음)
- 핵심 동작: 카드 뒤집기 → 다음 / 암기 완료 → 새로고침해도 상태 유지

## 기술 조건
- 빌드 도구 없이 index.html, style.css, app.js, words.js 4개 파일
- 바닐라 JS(ES 모듈), 외부 라이브러리·웹폰트 없음, 전체 용량 200KB 이하
- 단어 등 문자열은 textContent로만 출력 (innerHTML 금지)
- 상대 경로만 사용 (나중에 GitHub Pages에 그대로 올릴 예정)

## 구현할 기능
1. 기본 단어 세트 (F-07)
   - words.js에 고등학교 필수 영단어 50개: word, meaning, partOfSpeech, example
   - 뜻과 예문은 직접 작성 (상용 단어장 내용 복사 금지)
2. 카드 표시 (F-01)
   - 화면 중앙에 카드 1장. 앞면은 영단어(모바일 32px, PC 44px 이상)와 "탭해서 뜻 보기" 안내
   - 20자가 넘는 숙어는 줄바꿈
3. 뒤집기 (F-02)
   - 카드 클릭·탭 또는 Space·Enter → Y축 3D 회전 0.4초
   - 뒷면: 뜻(필수), 품사·예문(있을 때). 다시 누르면 앞면
   - prefers-reduced-motion이면 회전 없이 즉시 전환
   - 뒤집을 때마다 reviewCount +1
4. 다음 (F-03)
   - 카드 아래 "다음" 버튼 (48×48px 이상)
   - 다음 카드는 항상 앞면으로 시작
   - 마지막 카드에서 누르면 "한 바퀴 끝!" 안내 후 첫 카드로
5. 암기 완료 (F-04)
   - 누르면 memorized=true, memorizedAt 기록, 다음 카드로 자동 이동
   - 하단 토스트 "암기 완료로 표시했어요 · 되돌리기" 3초. 되돌리기는 상태와 카드 위치를 직전으로 복원
   - 이미 완료한 단어를 볼 때는 버튼이 "다시 외우기"로 바뀜
6. 학습 순서
   - 기본은 "미암기 단어만" 순서대로
   - 미암기가 0개면 임시로 "모두 외웠어요!" 문구만 표시 (완료 화면은 2단계)
7. 자동 저장 · 복원 (F-05)
   - 아래 AppState를 localStorage 키 "vocab-flashcards:v1"에 JSON으로 저장
   - 뒤집기·다음·암기 완료·되돌리기 직후 저장. "저장" 버튼은 없음
   - 시작 시 불러와 currentWordId(마지막 카드)에서 이어서 시작
   - 저장 데이터 없음 → 기본 세트로 초기화
   - JSON 파싱 실패·형식 불일치 → 원본을 "vocab-flashcards:backup"에 보관, 기본 세트로 시작, 안내 표시
   - localStorage 사용 불가(시크릿 모드 등) → 상단 배너 "이 창에서는 학습 기록이 저장되지 않아요", 메모리로만 동작
   - 모든 localStorage 접근은 try/catch로 감싸고, 다른 탭의 변경은 storage 이벤트로 반영

## 데이터 모델
Word = {
  id: string,            // crypto.randomUUID()
  word: string,          // 50자 이하
  meaning: string,       // 100자 이하
  partOfSpeech?: string, // n., v., adj. 등
  example?: string,      // 200자 이하
  memorized: boolean,
  memorizedAt?: string,  // ISO 날짜
  reviewCount: number,
  createdAt: string
}
AppState = {
  version: 1,
  words: Word[],
  currentWordId: string,
  filter: "unmemorized",
  shuffle: false,
  stats: { daily: { "YYYY-MM-DD": number }, streak: number }
}

## 화면
- 상단 바(높이 56px): 앱 이름 "영단어 카드", 오른쪽에 "남은 단어 n개"
- 카드: 화면 폭 90%, 비율 3:4, 모서리 16px. 폭 768px 이상에서는 가로 480px 가운데 정렬
- 하단 버튼 영역(높이 56px, 엄지가 닿는 하단 고정): "암기 완료"(초록 강조), "다음"
- 색: 배경 밝은 회색, 카드 흰색, 강조 초록. 색 대비 WCAG AA 이상
- 문구는 학생에게 말하듯 짧고 친근하게

## 완료 기준 (브라우저로 직접 확인하고 결과를 알려줘)
- [ ] 처음 열면 기본 세트의 첫 카드가 앞면으로 보인다
- [ ] 카드를 누르면 0.5초 안에 뜻이 보이고, 다시 누르면 앞면으로 돌아간다
- [ ] 뒤집힌 상태에서 "다음"을 눌러도 다음 카드는 앞면이다
- [ ] 10개 중 3개를 암기 완료 → 새로고침 → 완료 3개와 마지막 위치가 그대로다
- [ ] 되돌리기를 누르면 상태와 위치가 직전으로 돌아온다
- [ ] 저장 데이터를 일부러 깨뜨려도 앱이 멈추지 않고 안내가 나온다
- [ ] 320px 폭에서 가로 스크롤이 없다
```

### 구현 결과 (완료)

- 만든 파일: `index.html`, `style.css`, `app.js`, `words.js` (총 32KB)
- 로컬 실행: ES 모듈을 사용하므로 `index.html` 직접 더블클릭은 크롬에서 CORS로 막힐 수 있음 → `python -m http.server`로 로컬 서버를 띄워 확인
- 완료 기준: 7개 항목 모두 Playwright로 자동 조작 + 스크린샷으로 확인 완료 (콘솔 에러 0건)
- 비고: `reviewCount`는 앞면→뒷면으로 넘어갈 때(뜻을 확인한 시점)에만 +1 되도록 구현
