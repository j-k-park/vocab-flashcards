## A. 부가 기능
1. 발음 듣기 (F-13)
   - 카드 앞·뒷면에 스피커 버튼. Web Speech API speechSynthesis, lang "en-US", rate 0.9
   - 스피커 버튼을 눌러도 카드가 뒤집히지 않게
   - 지원하지 않는 브라우저에서는 버튼을 숨김
2. 내보내기 · 불러오기 (F-14)
   - 단어장과 암기 상태를 JSON 파일로 다운로드 (파일명 "vocab-backup-YYYY-MM-DD.json")
   - 불러오기: 파일 선택 → 형식 검증 → "현재 단어장을 덮어쓸까요?" 확인 후 적용
   - 잘못된 파일이면 기존 데이터를 건드리지 않고 오류 안내
3. 설정 화면 (메뉴에서 진입, #/settings)
   - "카드 넘길 때 발음 자동 재생" 켜기/끄기 (AppState.settings에 저장)
   - 내보내기, 불러오기
   - 전체 초기화: 기본 단어 세트 + 미암기 상태로. 확인 창 두 번

## B. 오프라인 · 홈 화면 추가 (PWA)
- manifest.webmanifest (이름 "영단어 카드", 아이콘 192·512px, display standalone)
- 서비스 워커로 정적 파일을 캐시해, 한 번 열었던 기기는 오프라인에서도 열리게. 코드를 고치면 캐시 버전이 바뀌어 새 파일이 반영되도록
- 첫 방문 시 한 번만 안내: "홈 화면에 추가하면 기록이 더 안전하게 남아요. 가끔 내보내기로 백업해 두세요"
  (학교 크롬북 로그아웃 시 데이터 삭제, iOS 사파리 7일 미방문 삭제에 대비)

## C. 품질 점검
- 접근성: 카드에 role과 aria-label(예: "영단어 abandon, 누르면 뜻 보기"), 뒤집으면 aria-live로 뜻을 알림. 색 대비 WCAG 2.1 AA(본문 4.5:1), 포커스 표시, prefers-reduced-motion 대응
- 다크 모드: prefers-color-scheme에 따라 자동 전환
- 성능: 전체 용량 200KB 이하(아이콘 제외), 버튼 반응 100ms 이내, Lighthouse 성능·접근성 90점 이상 목표
- 예외 상황: 시크릿 모드, 저장 데이터 손상, 단어 0개, 단어 1,000개(목록 스크롤·검색 속도)
- 화면 폭 320px~1920px에서 가로 스크롤 없음
- 발견한 문제는 고치고, 고치지 못한 것은 목록으로 남겨줘

**3단계 변경 요약**
- 발음 듣기: 카드 앞·뒷면 스피커 버튼(`speech.js`), 클릭해도 카드가 뒤집히지 않도록 이벤트 전파 차단. 발음 자동재생 설정 추가
- 내보내기/불러오기: `storage.js`에 `validateImportShape`·`replaceAll` 추가, JSON 파일로 백업/복원. 형식 오류·필수 필드 누락은 기존 데이터를 건드리지 않고 오류 안내
- 설정 화면(`settings.js`, `#/settings`): 발음 자동재생 토글, 내보내기/불러오기, 확인창 2번짜리 전체 초기화. 상단 메뉴를 드롭다운으로 바꿔 "단어 관리"·"설정" 두 항목 제공
- PWA: `manifest.webmanifest` + `sw.js`(캐시 우선 전략)로 오프라인 지원, 첫 방문 시 1회 홈 화면 추가 안내 배너
- 품질: 다크 모드(`prefers-color-scheme`) 전체 반영, 본문 텍스트 대비 강화(#6b6b70→#5b5b60), 카드 뒤집힘 시 `aria-live`로 뜻 안내, 보이지 않는 면은 `aria-hidden`·`pointer-events:none` 처리(뒷면이 클릭·접근성 트리를 가로채던 실제 버그를 테스트 중 발견해 수정)

**남은 이슈**
- Lighthouse 성능 하위 항목 중 `Minify CSS/JS`, `Render-blocking requests`, `Network dependency tree`가 감점 요인 — 빌드 도구·번들러를 쓰지 않는다는 프로젝트 조건상 의도적으로 미적용. 실제 배포(GitHub Pages)에서는 CDN 압축·캐시 헤더가 자동 적용되어 `Document request latency`·`cache-insight` 항목은 로컬 테스트 서버(Python http.server)보다 나아질 것으로 예상됨
- 발음 자동재생은 무음 모드·자동재생 차단 브라우저 정책에 따라 첫 상호작용 전에는 재생이 지연될 수 있음(브라우저 표준 동작, 앱에서 우회하지 않음)
- Lighthouse의 `label-content-name-mismatch`(실험적 감사, 채점 비반영)가 카드 컨테이너에서 감지되어 원인을 확인 후 보이지 않는 면에 `aria-hidden`을 추가로 적용함(위 품질 항목 참고)
