# 영단어 카드

학생이 자기 손으로 단어장을 만들고, 카드를 뒤집으며 외우는 영단어 플래시카드 웹앱입니다.
설치·로그인·서버 없이 브라우저에서 바로 열리는 정적 웹앱이고, 빌드 도구나 외부 라이브러리를 쓰지 않았습니다.

## 사용법

1. `index.html`을 웹 서버로 열면(아래 "로컬에서 실행하기" 참고) 기본 영단어 50개로 학습을 시작합니다.
2. 카드를 탭하면 뜻이 보이고, "다음/이전"으로 카드를 넘기며 "암기 완료"로 외운 단어를 표시합니다.
3. 상단 진도 막대 아래 탭에서 "미암기 / 전체 / 암기 완료"로 보기를 바꾸고, "섞기"로 순서를 무작위로 바꿀 수 있습니다.
4. 왼쪽 위 메뉴(☰)에서 **단어 관리**(직접 추가·붙여넣기로 일괄 추가·검색·수정·삭제)와 **설정**(발음 자동재생, 내보내기/불러오기, 전체 초기화)으로 이동합니다.
5. 카드의 스피커 아이콘을 누르면 영단어 발음을 들을 수 있습니다(브라우저가 지원할 때만 표시).

### 단축키 (폭 768px 이상 화면 하단에 안내가 표시됩니다)

| 키 | 동작 |
| --- | --- |
| `Space` | 카드 뒤집기 |
| `←` / `→` | 이전 / 다음 카드 |
| `Enter` | 암기 완료 |

모바일에서는 카드를 좌우로 스와이프해도 이전/다음으로 넘어갑니다.

## 파일 구조

```
index.html            학습 · 단어 관리 · 설정 화면 마크업
style.css             전체 스타일 (다크 모드·반응형 포함)
words.js              기본 영단어 50개 데이터
storage.js            상태 저장/복원, localStorage 동기화, 내보내기/불러오기 검증
app.js                학습 화면 로직 + 라우팅 + 부트스트랩(서비스 워커 등록 포함)
manage.js              단어 관리 화면(추가/수정/삭제/검색/일괄 추가)
settings.js            설정 화면(발음 자동재생, 내보내기/불러오기, 전체 초기화)
toast.js                공용 토스트 알림
speech.js               발음 듣기(Web Speech API) 래퍼
manifest.webmanifest    PWA 매니페스트 (홈 화면 추가)
sw.js                    서비스 워커 (오프라인 캐시)
icons/                   PWA·파비콘 아이콘
prd/                     단계별 PRD 문서 (1~3단계)
```

## 데이터 저장 방식과 한계

- 모든 데이터(단어, 암기 상태, 필터·섞기, 학습 통계, 설정)는 브라우저의 `localStorage`에 `vocab-flashcards:v1` 키로 저장됩니다.
- **같은 기기, 같은 브라우저에서만 유지됩니다.** 다른 기기·다른 브라우저·시크릿 모드에서는 보이지 않습니다.
- 학교 크롬북처럼 로그아웃 시 브라우저 데이터가 지워지는 환경, iOS 사파리처럼 7일 이상 미방문 시 데이터가 삭제될 수 있는 환경에서는 **설정 → 내보내기**로 주기적으로 JSON 백업을 받아두는 것을 권장합니다.
- 저장 데이터가 손상되었거나 시크릿 모드 등으로 저장이 불가능한 경우, 화면 상단에 안내 배너가 표시되고 기본 세트로 안전하게 시작합니다.

## PWA (홈 화면 추가 · 오프라인)

- `manifest.webmanifest`와 `sw.js`를 통해 모바일 브라우저의 "홈 화면에 추가" 기능을 지원하고, 한 번 방문한 기기는 오프라인에서도 앱이 열립니다.
- 코드를 수정한 뒤에는 `sw.js`의 `CACHE_NAME` 버전 문자열(`vocab-flashcards-v1` 등)을 올려주세요. 그래야 사용자 브라우저가 새 파일을 다시 받아옵니다.

## GitHub Pages로 배포하기

1. 이 폴더를 GitHub 저장소에 푸시합니다(이미 `git init`과 첫 커밋은 되어 있습니다).
   ```bash
   git remote add origin <저장소 URL>
   git push -u origin main
   ```
2. GitHub 저장소의 **Settings → Pages**에서 Source를 `main` 브랜치(루트 `/`)로 설정합니다.
3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 됩니다.
4. 모든 리소스가 상대 경로(`./`)로 되어 있어 하위 경로(`/저장소명/`)에 배포해도 그대로 동작합니다.

## 로컬에서 실행하기

ES 모듈(`import`)을 사용하므로 `index.html`을 더블클릭해서 여는 방식은 일부 브라우저(크롬 등)에서 CORS로 막힙니다. 로컬 서버로 열어주세요.

```bash
cd vocab-flashcards
python -m http.server 5173
```

그다음 브라우저에서 `http://localhost:5173`으로 접속합니다.
